# Фінальний проєкт

## Завдання 7. Метод Монте-Карло: кидання двох кубиків

У [task_7.py](task_7.py) змодельовано 100 000 кидків двох кубиків. Під час кожного випробування генеруються два випадкові цілі числа від 1 до 6, обчислюється їхня сума та збільшується її лічильник. Імовірність суми оцінюється як кількість її появ, поділена на кількість випробувань.

Для відтворення результату використано `random.Random(42)`. Аналітичні ймовірності взято з таблиці в умові завдання.

| Сума | Монте-Карло | Аналітично |
| --- | ---: | ---: |
| 2 | 2.80% | 2.78% |
| 3 | 5.59% | 5.56% |
| 4 | 8.30% | 8.33% |
| 5 | 11.22% | 11.11% |
| 6 | 13.84% | 13.89% |
| 7 | 16.46% | 16.67% |
| 8 | 13.92% | 13.89% |
| 9 | 11.18% | 11.11% |
| 10 | 8.30% | 8.33% |
| 11 | 5.59% | 5.56% |
| 12 | 2.81% | 2.78% |

### Висновки

Отримані ймовірності близькі до аналітичних значень з умови. Найчастіше випала сума 7, а найрідше — суми 2 та 12. Це відповідає кількості пар результатів кубиків: для суми 7 є шість пар, а для сум 2 та 12 — по одній.

Невеликі відмінності між симуляцією та аналітичними значеннями очікувані: метод Монте-Карло оцінює ймовірності за скінченною випадковою вибіркою. Результати цього запуску узгоджуються з таблицею умови.
